# 部品基本信息取得规则

## 1. 部品基本信息表的判定

PDF 上的表格同时带有 `番号`、`部品名`、`枠区分` 三列表头时，该表即为**部品基本信息**。
其它表格（タイプ名表、図番表、标题栏等）不作为部品基本信息。

## 2. 取得项目（13 列，顺序固定）

`部材名`｜`部品名`｜`区分`｜`数量`｜`切断寸法`｜`部品ｺｰﾄﾞ`｜`参照元`｜`H下限`｜`H上限`｜`W下限`｜`W上限`｜`使い分け`｜`特注`

- 表体 1 行 = 1 个部品；一张图有多张部品表时按图面顺序（上→下、左→右）拼接。
- 有对应列 → 取单元格文字；列名对应：`枠区分`→`区分`、`員数`→`数量`、`部品コード`→`部品ｺｰﾄﾞ`。
- 合并单元格 → 取合并区域左上角单元格的内容。
- PDF 无该列 → 留空（空字符串）；单元格本身为 `-` → 原样保留 `-`。
- `番号`、`基本寸法` 不取；`品種` 也不输出，仅用于第 5 章的筛选判定。
- `部材名` = 圈号附近的构件名，按第 3 章取；取不到 → 留空。
- `参照元` = **用户提示的 PDF（父图）**图面右下角标题栏里的图番（不取文件名、不取要領図 列表的 `図番` 列）；结果表所有行都填同一值。该处名称里同时带有品种要素，第 5 章据此判品种。

## 3. 番号・圈号的用途（部材名／行分割）

部品表的 `番号` N 对应图面上的圈数字（`①`＝1、`②`＝2…）。圈号用于两件事：定 `部材名`、定是否行分割。

**① 部材名**：取圈号位置的文字中「像部材名」的那个。

- 范围：只在该圈号所属的**零件图（Part）**内找（`parts_text.txt` 的 `[Part_xx]` 区块），**不跨 Part**——否则会误取相邻零件图的构件名（如 `⑤` 按全局最近会误取 `上用戸当り`）。
- 候选优先级：构件名（安装基体，见下条）＞ 图块标题 `【…】`（去括号）＞ 留空。
- 优先取**安装基体**（縦枠／上枠／下枠／沓摺／溝フタ／戸当り／スペーサー）；被安装部品自身的组成件（如 `表面プレート`／`受けボックス`／`台座` 属ストライク受け 的构件）不计入候选。
- 排除：`Ａ部`／`Ｂ部`／`■…取付`（区块标记）、圈号自身（`①1`）、型番（`MDW754R`／`MEA□708L/R`／`LAVS639`／`BI-214`）、尺寸与数字（`1`／`50`／`13mm以下`）、施工说明句（含 `する`／`こと`／`。`／`※`／`注）`）。
- 同 Part 内有多个构件名（如左右对称的 `戸先側縦枠`／`戸尻側縦枠`）→ 取与圆心**距离最近**的；最近两者距离差 <10% 视为无法判定 → 留空并列入待确认。
- 分割后每行按各自的圈号位置分别取 `部材名`（可不同）。

**② 行分割**：同一番号在图面上出现**多处**时，该行按出现处数拆成多行，`部品名` 加方位前缀。

- **圈号取处**：`callouts.txt` 的圆心绝对坐标（页面像素）优先；该图为 0 处时取文字层圈字符的绝对坐标，且只认零件图区域内「圈号＋部品名（＋型番）」式标签，排除以 `。`／`する`／`こと` 结尾的施工手順正文（步骤编号不算标注）。
- **匹配**：`番号` 为空或非数字 → 不处理；找不到对应圈号 → 不分割；只出现 1 次 → 原样 1 行。
- **出现 k≥2 次**：复制成 k 行，`区分`／`数量`／`切断寸法`／`部品ｺｰﾄﾞ`／`参照元` 一律原样复制，只改 `部品名`。
- **方位**（用绝对坐标，不用各零件图的局部坐标）：
  - Y 跨度 ≥ X 跨度 → 纵向：按 cy 升序标 `上`、`下`；k=3 → `上`/`中`/`下`；k≥4 → `上1`、`上2`…
  - 否则 → 横向：按 cx 升序标 `左`、`右`；k=3 → `左`/`中`/`右`；k≥4 → `左1`、`左2`…
- **前缀格式**：`上_部品名`（分隔符 `_`）。
- 同一番号的多处圈号若带**完全相同**的标注文字，多为同一件的状态示意图（如タップが見える／隠れている），分割后须人工确认。

## 4. 要領図 列表的展开

父图表头为 `項目`／`図番` 的表即**要領図 列表**（常由 `注)2.…下記に示す図面を参照のこと。` 引出；无法识别成表格时，取与「要領」同行的图番文字）。

1. 按列表行顺序，用图番定位对应 PDF。
2. 在该 PDF 上按第 1、2 章取其部品 → 按第 3 章分割 → 按本节 `項目 分割` → 按第 5 章筛选，追加到结果。
3. 只展开一层，不递归；PDF 缺失或该图无部品表时跳过。

**項目 分割**：`項目` 列（`A`／`B`…）指向**父图上的 `Ａ部`／`Ｂ部`** 视图标记。合并单元格取左上角，即一个 `項目` 覆盖到下一个非空 `項目` 之前的所有行。统计该标记在父图各 Part 中出现的次数 k，按与第 3 章相同的规则处理：

- k=1 或父图上找不到该标记 → 不分割。
- k≥2 → 该要領図 展开出的**每一行**按 k 复制，`部品名` 前加方位（Y 跨度 ≥ X 跨度 → `上`/`下`；否则 → `左`/`右`；k=3 → `上`/`中`/`下`；k≥4 → `上1`、`上2`…）。
- 与第 3 章圈号分割**叠加**时先圈号、后 `項目`，前缀由外到内为 `項目方位_圈号方位_部品名`（如 `上_下_丁番裏板R`）。
- 输出顺序：先按 `項目` 方位（上→下、左→右），同一方位内再按圈号方位。
- `項目` 为空 → 不按视图分割。

## 5. 品种筛选（仅要領図 的部品）

父图的品种**不取自** `品種` 列，也**不取** `タイプ名` 表，而是取自**用户提示的 PDF 右下角名称里带有的品种要素**。以 `H453U10001` 为例，右下角名称 = `H453`／`18ラフィス`／`標準ドア`／`ライン枠`／アッセンブリ図／`H453U10001`，其中品种要素 = `18ラフィス`（系列）、`標準ドア`（门种）、`ライン枠`（框种）；这些要素构成品种集合 **P**。

| 要領図 部品 | 处理 |
| --- | --- |
| 带品种，值 ∈ P | 有效（是对象） |
| 带品种，值 ∉ P | 丢弃（不是对象） |
| 带品种，但 P 为空 | 全部有效 |
| 不带品种（无 `品種` 列或值为空） | 全部有效 |

- `品種` 值去前后空白后，与 P 中任一要素**完全相同**或**含有**该要素 → 视为存在（∈ P）；否则不存在（∉ P）。
- 全角/半角、大小写差异不视为同一。
- `タイプ名` 表不参与品种判定。

## 6. 合并与输出

1. 父图部品在前（按表行序）；要領図 部品依次追加（按图番顺序 × 各表行序）。
2. `部品ｺｰﾄﾞ`＋`部品名`＋`区分` 相同视为同一部品，保留先出现者（父图优先）。
3. 输出 13 列，表头用第 2 章的日文列名，编码 UTF-8。

## 7. 示例（H453U10001アセンブリ図）

- 要領図 列表：`H453U10002`（5 行）、`H453U10003`（2 行）、`H453U10004`（1 行）。父图右下角品种要素 P = `18ラフィス`／`標準ドア`／`ライン枠`；四张图均无 `品種` 列 → 全部有效（不触发比对）。
- 圈号：`H453U10001` 6 处（①〜⑥ 各 1 次）→ 不分割；`H453U10002` ①×2、②×2（同一标签 `①②丁番裏板`，y＝146／486，纵向）→ 拆 `上_`／`下_`，③④⑤ 各 1 次；`H453U10003` ①×1、②×1；`H453U10004` ①×1。
- `項目` 分割：`A` 合并覆盖 `H453U10002`＋`H453U10003`、`B` 对应 `H453U10004`；父图 `Ａ部` 2 处（Part_04 y＝1771／3709，纵向→上/下）、`Ｂ部` 2 处（Part_02 x＝3700＋Part_04 x＝6170，横向→左/右）。故 U10002 7×2＝14 行、U10003 2×2＝4 行、U10004 1×2＝2 行。
- 部材名（按第 3 章）：`H453U10001` ①=戸尻側縦枠、②=上枠、③=空（候选均距 ≈2330、差 2%，无法判定）、④=埋込沓摺、⑤=入隅用スペーサー、⑥=戸尻側縦枠；`H453U10002` 5 行无构件名 → 空；`H453U10003` ①=ストライク側縦枠、②=上枠セット（取其图块标题 `【上枠セット】`）；`H453U10004` ①=ストライク側縦枠。
- `参照元`：所有行统一填用户提示的父图 `H453U10001`（取该 PDF 右下角标题栏的图番，不取文件名／要領図 列表的 `図番` 列）；同一处名称里带有的品种要素见本章第 1 条。
- 合计 6＋14＋4＋2＝**26 行**。若 `項目` 分割与圈号分割视为同一维度而互斥（不叠加），则为 6＋10＋4＋2＝**22 行**；若两者都不拆，则为 14 行。
